One razor-sharp line, at most 200 characters, that excuses you from a pointless work meeting or Zoom call — the mute button finally wants a word.

## Run it

```sh
python3 main.py
```

Writes a single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Fully deterministic: no randomness, no clock, no network.
